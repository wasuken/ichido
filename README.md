# 無能向けタスク管理ツール

一度にごちゃごちゃといくつものことを抜かすな、私たちは一つの関心事しか頭に置くことができないのだから。

タスクの入力欄では `買い物 #暮らし` のようにタグを付けられます。入力欄にフォーカスしている間は、直下に「#」ボタンとタグチップの横スクロールツールバーを表示します。「#」ボタンでタグを書き始められ、チップをタップするとタグと末尾の空白を挿入します。単語の直後では先頭にも空白を補います。タスクを追加するとタグが履歴に登録され、新しく登録した順にチップを表示します。`#` に続けて入力中は前方一致の候補だけを太い枠・背景色・太字で強調し、タップするとカーソル位置のタグ全体を補完します。操作後もキーボードを開いたまま続けて入力できます。日本語や、1行に複数のタグを入力することにも対応しています。

「いまやる」では、未完了タスクに使われているタグを横並びのチップで表示します。1つ選ぶと NOW / NEXT をそのタグの完全一致で絞り、もう一度タップすると解除します。完了と順番交換も絞り込み後のタスクが対象です。選択タグを使う未完了タスクがなくなると自動解除します。選択状態は保存しません。

タグは行頭か空白直後の `#` から始まります。本文には残し、タスクのタグ配列にも保存します。

タグ履歴は端末内に保存され、アプリの再起動やタスクの削除後も利用できます。

「一覧」では本文を部分一致で検索できます。完了済みも対象で、英字の大文字・小文字は区別しません。「クリア」で全件表示に戻ります。

「タグ」ではタグ名を入力して追加できます。登録済みのタグをタップすると、「一覧」に移動して `#タグ名` を通常の部分一致で検索します。追加したタグはタスク入力時の補完候補にも表示されます。

検索とタグのテストは Node.js 22.6 以降で `npm test`、型チェックは依存関係のインストール後に `npx tsc --noEmit` で実行できます。
